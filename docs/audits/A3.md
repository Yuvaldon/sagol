Audit run: 2026-11-10, read-only, on branch `v5-approval` at `d01f840` (end of V5, before its merge). `npm run check`: 722
tests green. Playwright and the build were not run. At the owner's request the audit had a second part: the quality of the

said ☑. It was closed before this record: the e2e budget is 60 s (the V5 handoff explains it) and the pull request merged
green. The rest are seams that cost more later: an edit saved by two commands, a leave that no screen reaches, and the rule
gate and hint comparison tested on fewer paths than the decisions name.

## What was checked and found in order

- **Leave commands:** the order of checks matches D-114 and D-117 (visibility, permission, `stale_version`, state,
  references, `no_changes`, the rule gate), all in one transaction.
- **Comments:** read and written by their visibility; only the author edits (D-118).
- **Hints and optimistic updates:** derived from the same state machine as the commands, and taken back on a refusal.
- **View state:** all in the URL; an invalid value counts as absent (D-103, D-104, D-112).
- **Timeline engine:** a pure core with tests, and a single adapter to the domain.
- **V5 commits:** each touches one layer.
- **Not read:** M1 code, the dictionary and most primitives.
